# Hochspannung

Netzausbau-Strategiespiel für das Handy: Kraftwerke ersteigern, Rohstoffe kaufen und ein Stromnetz über Deutschland bauen, gegen 2–3 KI-Gegner.

**Spielen:** https://pups-flatus-png.github.io/hochspannung/

## Als App installieren

1. Die Adresse oben einmal auf dem Handy öffnen (mit Internet).
2. iPhone: Safari → Teilen → „Zum Home-Bildschirm“.
   Android: Chrome → Menü → „App installieren“.
3. Danach startet das Spiel vom Home-Bildschirm, auch offline.

Spielstand und Statistik werden nur auf dem jeweiligen Gerät gespeichert.
